MANASI TONDE — PORTFOLIO WEBSITE

Files:
- index.html: portfolio content
- style.css: responsive styling and colors
- script.js: mobile navigation

HOW TO VIEW:
1. Extract the ZIP file.
2. Open the folder.
3. Double-click index.html to view it in your browser.

BEFORE PUBLISHING:
- Add your actual LinkedIn profile URL in index.html (search for "Add your LinkedIn profile URL").
- Add project GitHub links, screenshots, and live demos when available.
- Review the skills list and keep only the skills you can comfortably discuss in an interview.
- MSc is written as "MSc Artificial Intelligence and Data Science (MSc AIDS) at Indira University" as you specified.

PUBLISH FREE WITH GITHUB PAGES:
1. Create/sign in to GitHub and create a repository named manasi-tonde-portfolio.
2. Upload index.html, style.css, and script.js to the repository root.
3. Open Settings → Pages.
4. Under Build and deployment, select Deploy from a branch, choose main and /(root), then Save.
5. Wait for GitHub Pages to provide your published website URL.
